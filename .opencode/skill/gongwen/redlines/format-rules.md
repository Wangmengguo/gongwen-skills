# 公文格式红线

> 本文件在定稿前加载，用于最终格式检查。
> 
> 格式是公文的"门面"，格式错误会让内容的专业性大打折扣。

## 一、标点符号

### 必须使用全角中文标点

| 类型 | 正确 | 错误 |
|------|------|------|
| 逗号 | ， | , |
| 句号 | 。 | . |
| 引号 | ""'' | "" '' |
| 冒号 | ： | : |
| 分号 | ； | ; |
| 问号 | ？ | ? |
| 感叹号 | ！ | ! |
| 顿号 | 、 | 无对应 |

### 引号规范

1. 正文使用中文全角双引号：“”
2. 引号嵌套时，外层“”，内层‘’
3. 引号必须成对，不得悬空
4. 引用文件原文时，保持原文引号形式

**示例**：
```
正确：落实招商引资“一号工程”
错误：落实招商引资"一号工程"
```

## 二、排版规范

### 禁止 Markdown 格式符号

公文正文中禁止出现：
- `**加粗**` → 应直接写文字
- `*斜体*` → 公文不用斜体
- `# 标题` → 公文标题另有格式
- `- 列表` → 公文用"一、（一）、1."

### 小标题融入段落

**错误**（小标题独立成行）：
```
**（一）突出政治引领，思想共识持续巩固。**

坚持把理论学习摆在首位……
```

**正确**（小标题融入段落）：
```
（一）突出政治引领，思想共识持续巩固。坚持把理论学习摆在首位……
```

### 序号规范

| 层级 | 格式 | 示例 |
|------|------|------|
| 一级 | 中文数字+顿号 | 一、二、三、 |
| 二级 | 括号中文数字 | （一）（二）（三） |
| 三级 | 阿拉伯数字+点 | 1. 2. 3. |
| 四级 | 括号阿拉伯数字 | （1）（2）（3） |

## 三、数值规范

### 禁止未经确认的数值

- 所有数据必须与用户核实
- 缺失数值处标注 `【待补充：具体数值】`
- 涉及金额、比例、数量必须二次确认

### 统计类数值复核流程

当 AI 需要从表格/列表中按条件筛选并统计数量时，**禁止直接输出统计结果**，必须执行以下流程：

**第一步：声明筛选条件**

```
筛选条件：[具体条件，如"投资金额 ≥ 10亿元"]
数据来源：[文件名]（共 X 条记录）
```

**第二步：分批输出明细**

- 每批 10-15 条
- 每批末尾显示：本批 X 条 | 累计 Y 条
- 全部输出后显示：筛选完成，符合条件共 Z 条

**第三步：用户确认后写入**

- 用户确认总数无误后，才可将数值写入正文
- 如用户发现遗漏或多计，根据反馈修正

**示例**：

```
筛选条件：投资金额 ≥ 10亿元
数据来源：全市重点在谈项目.md（共52条记录）

【符合条件的项目明细】
| 序号 | 项目名称 | 投资金额 | 属地 |
|------|----------|----------|------|
| 1 | 储能电池项目 | 30亿元 | 投促中心 |
| 2 | 慈溪市物流园区项目 | 20亿元 | 交通集团 |
| ... | ... | ... | ... |

本批：10条 | 累计：10条

---
筛选完成。符合条件共 10 条，是否确认写入正文？
```

> ⚠️ **红线**：统计类数值必须经用户确认后才可写入正文，AI 不可跳过复核流程直接使用统计结果。

### 数字表述

| 场景 | 用法 | 示例 |
|------|------|------|
| 统计数据 | 阿拉伯数字 | 完成172亿元 |
| 序数词 | 中文数字 | 第一季度 |
| 约数 | 中文数字 | 十余人 |
| 年份 | 阿拉伯数字 | 2025年 |

## 四、语言禁区

### 禁用词

| 禁用 | 替代 | 原因 |
|------|------|------|
| 当务之急 | 当前重点推进 | 偏口语化 |
| 势在必行 | 需要加快推进 | 过于绝对 |
| 刻不容缓 | 需要抓紧落实 | 过于情绪化 |

### 慎用表述

| 慎用 | 问题 | 建议 |
|------|------|------|
| 进一步 | 堆砌显空洞 | 每篇最多3次 |
| 切实 | 过度使用无意义 | 关键处用1-2次 |
| 不断 | 缺乏具体性 | 改为具体措施 |
| 大力 | 态度词泛滥 | 用数据说话 |

## 五、政治表述红线

### 必须规范的表述

以下表述有固定写法，不得改写：

| 规范表述 | 不可改写为 |
|----------|------------|
| 习近平新时代中国特色社会主义思想 | 新时代思想、习思想 |
| 党的二十大精神 | 二十大精神（缺"党的"） |
| 增强"四个意识" | 四个意识（缺引号） |
| 坚定"四个自信" | 四个自信（缺引号） |
| 做到"两个维护" | 两个维护（缺引号） |

### 时间节点表述

| 年份 | 正确表述 | 错误表述 |
|------|----------|----------|
| 2025年 | “十四五”收官之年 | 十四五最后一年 |
| 2026年 | “十五五”开局之年 | 十五五第一年 |

## 六、定稿检查清单

每次定稿前，逐项检查：

### 标点
- [ ] 是否全部使用全角中文标点？
- [ ] 引号是否成对且使用“”？
- [ ] 是否有残留的半角标点？

### 排版
- [ ] 是否有残留的 Markdown 符号？
- [ ] 小标题是否融入段落？
- [ ] 序号层级是否正确？

### 数值
- [ ] 所有数据是否已与用户确认？
- [ ] 是否有未填充的【待补充】？

### 语言
- [ ] 是否有禁用词？
- [ ] “进一步”“切实”是否过度使用？
- [ ] 政治表述是否规范？

### 整体
- [ ] 朗读一遍是否通顺？
- [ ] 有无错别字？
- [ ] 人名、单位名是否准确？
