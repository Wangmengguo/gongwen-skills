# 公文写作核心原则

> 这份文件回答一个根本问题：**什么是好公文？**
> 
> 在学习任何格式规范之前，请先内化这些原则。规则可以查表，智慧需要理解。

## 一、公文的本质

公文是**推动工作的工具**，不是展示文采的舞台。

### 1.1 公文的三个功能

| 功能 | 说明 | 判断标准 |
|------|------|----------|
| **传递信息** | 让读者知道发生了什么 | 读完后能否用一句话复述要点？ |
| **推动决策** | 让领导能做出判断 | 信息是否充分支撑决策？ |
| **指导行动** | 让执行者知道怎么做 | 执行者读完是否清楚下一步？ |

**自检**：如果你的公文读完后，读者不知道"要干嘛"，那就是失败的公文。

### 1.2 公文不是什么

- **不是散文**：不需要华丽辞藻，不需要情感渲染
- **不是论文**：不需要完整的论证链条，只需要结论和关键依据
- **不是日记**：不需要事无巨细的流水账，只需要有价值的信息

## 二、好公文的判断标准

### 2.1 金字塔原则

好公文遵循**结论先行，层层支撑**的结构：

```
        ┌─────────────┐
        │   核心结论   │  ← 读者最先看到的
        └──────┬──────┘
    ┌──────────┼──────────┐
    ▼          ▼          ▼
┌───────┐ ┌───────┐ ┌───────┐
│ 论据1 │ │ 论据2 │ │ 论据3 │  ← 支撑结论的要点
└───────┘ └───────┘ └───────┘
```

**反面典型**：
> "今年以来，我们认真贯彻落实上级精神，深入学习领会重要指示，扎实推进各项工作，在同志们的共同努力下，取得了一定成绩……"（读了100字还不知道要说什么）

**正面典型**：
> "2025年，全市招商引资完成内资172亿元，完成率101%。主要做法有三点：……"（开头即结论）

### 2.2 信息密度

**每句话都要有信息量。**

| 类型 | 示例 | 评价 |
|------|------|------|
| 空话 | "高度重视、精心组织、周密部署" | 无信息量，可删 |
| 套话 | "在市委市政府的坚强领导下" | 必要的政治表态，保留但不堆砌 |
| 实话 | "全年落地亿元项目43个，开工率79%" | 有信息量，核心内容 |

**自检**：删掉这句话，文章是否缺失信息？如果不缺，就删掉。

### 2.3 读者视角

写之前问自己：**读者是谁？他关心什么？**

| 读者类型 | 关心什么 | 写法调整 |
|----------|----------|----------|
| 上级领导 | 结论、问题、需要决策的事项 | 简洁、直击要点 |
| 平级部门 | 协作要求、时间节点 | 清晰、可操作 |
| 下级执行者 | 具体任务、标准、责任 | 明确、无歧义 |
| 公众 | 与自己的关系、能获得什么 | 通俗、有温度 |

## 三、常见问题与破解

### 3.1 "假大空"问题

**症状**：通篇正确的废话，读完不知所云。

**病因**：写作者不清楚"这份材料要解决什么问题"。

**破解**：
1. 动笔前写一句话：这份材料要让读者知道______，做出______决定。
2. 每段写完问自己：删掉这段，目标还能达成吗？

### 3.2 "流水账"问题

**症状**：一月做了A，二月做了B，三月做了C……

**病因**：按时间顺序罗列事实，缺乏提炼。

**破解**：
1. 先分类再叙述（如按"战略-执行-保障"分）
2. 每个分类提炼一个观点，事实服务于观点

### 3.3 "八股文"问题

**症状**：三个"进一步"、四个"切实"、五个"不断"……

**病因**：依赖模板，缺乏对内容的真正理解。

**破解**：
1. 写完后朗读一遍，问自己"我说话时会这么说吗？"
2. 把套话替换为具体行动或数据

## 四、写作的"编织"思维

公文写作的本质是**编织**：将零散的素材（数据、事实、观点）编织成一个有说服力的叙事。

### 4.1 素材收集

| 素材类型 | 作用 | 优先级 |
|----------|------|--------|
| 核心数据 | 支撑结论 | 高 |
| 典型案例 | 具象化成效 | 高 |
| 制度文件 | 体现规范性 | 中 |
| 领导讲话 | 政治正确性 | 中 |
| 背景信息 | 帮助理解 | 低 |

### 4.2 叙事结构

不同公文有不同的叙事结构，但核心模式只有几种：

| 模式 | 适用场景 | 结构 |
|------|----------|------|
| **成果汇报** | 述职、总结 | 做了什么 → 效果如何 → 下步打算 |
| **问题解决** | 整改、建议 | 问题是什么 → 原因分析 → 解决方案 |
| **人物事迹** | 先进典型 | 身份定位 → 突出事迹 → 精神升华 |
| **工作部署** | 方案、通知 | 为什么做 → 做什么 → 怎么做 → 谁来做 |

### 4.3 编织技巧

1. **先搭骨架再填肉**：先写小标题，确认逻辑通顺后再展开
2. **一段一个观点**：每段的第一句话是观点，后面是支撑
3. **过渡要自然**：段落之间要有逻辑连接，不能硬拼

## 五、政治表态的分寸

公文中必然涉及政治表态，关键是**恰到好处**。

### 5.1 必须有的表态

- 开头提一句"在市委市政府的坚强领导下"
- 涉及重大政策时引用上级文件精神
- 结尾表决心时用规范表述

### 5.2 避免的问题

- **堆砌**：三个"深入"四个"切实"五个"不断"
- **空转**：只有表态没有行动
- **拔高**：把日常工作说成重大创新

### 5.3 分寸把握

| 场景 | 表态强度 | 示例 |
|------|----------|------|
| 日常汇报 | 低 | "按照部署要求，扎实推进……" |
| 年度述职 | 中 | "坚持以习近平新时代中国特色社会主义思想为指导……" |
| 重大专项 | 高 | "深入贯彻落实党的二十大精神和习近平总书记重要指示批示精神……" |

## 六、自检清单

每次完成初稿后，问自己：

1. [ ] 读者是谁？我写的内容他需要吗？
2. [ ] 核心结论是什么？前100字能看出来吗？
3. [ ] 每段的观点是否清晰？能否一句话概括？
4. [ ] 是否有正确的废话？删掉后影响理解吗？
5. [ ] 政治表态是否恰当？不多不少？
6. [ ] 朗读一遍是否通顺？有没有绕口的句子？

---

**记住**：好公文不是写出来的，是**改出来的**。第一稿允许粗糙，但交稿前必须打磨。
