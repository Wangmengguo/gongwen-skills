# 公文撰写反馈记录

> 本文件记录用户反馈、常见错误、成功经验，用于持续改进 Skill 质量。

## 使用说明

每次撰写公文后，如有值得记录的经验，按以下格式追加：

```markdown
### [日期] [公文类型]

**用户反馈**：
- 正面：...
- 改进：...

**经验总结**：
- ...

**是否需要更新 Pattern**：是/否
```

---

## 反馈记录

<!-- 示例条目 -->

### 2025-01-27 述职报告

**用户反馈**：
- 正面：数据开头的方式很好，领导认可
- 改进：问题不足部分可以再具体一些

**经验总结**：
- 问题不足不能太空泛，要点到具体短板（如"外资缺口X%"）
- 政治表态部分不宜过长，1-2句即可

**是否需要更新 Pattern**：否（已在 shuzhi.md 中涵盖）
