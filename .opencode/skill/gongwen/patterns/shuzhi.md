# 述职报告撰写指南

> 述职报告的本质：**向组织交账**。回答"我（们）干了什么、干得怎么样、有什么问题、下步怎么办"。

## 一、核心逻辑

无论领导班子述职还是个人述职，底层逻辑一致：

```
政治站位 → 履职成效 → 问题不足 → 改进方向
   ↓           ↓           ↓          ↓
 态度正确    成绩扎实    敢于直面    方向明确
```

**读者视角**：组织考核干部时，首先看政治态度，其次看工作实绩，再看自我认知，最后看发展潜力。述职报告的结构要服务于这个判断过程。

## 二、类型区分

| 类型 | 视角 | 主语 | 侧重点 |
|------|------|------|--------|
| 领导班子述职 | 单位整体 | "班子""中心" | 整体工作、制度建设 |
| 个人述职 | 个人 | "本人""我" | 岗位职责、个人成长 |

## 三、结构框架

### 领导班子述职（建议4000-5500字）

```
导言（约5%）
├── 年度定位（如"十四五收官之年"）
├── 指导思想
└── 过渡句

第一部分：政治建设（约15%）
├── 理论学习（第一议题、中心组学习次数）
├── 重大精神贯彻（二十届全会等）
└── 政治表态

第二部分：核心业务（约45%）
├── 总体成效（开头用数据总括）
├── 工作举措（3-4条，每条"机制+做法+成效"）
└── 亮点案例

第三部分：从严治党（约20%）
├── 主体责任
├── 制度建设
└── 作风建设

第四部分：队伍建设（约10%）
├── 培训培养
└── 能力提升

结语（约5%）
├── 成绩回顾（1-2句）
├── 问题不足（3-4条，简明扼要）
└── 明年展望
```

### 个人述职（建议1200-1800字）

```
导言
├── 岗位定位
└── 过渡句

一是政治建设（入党进展、理论学习）
二是核心业务（岗位职责完成情况）
三是日常履职（服务保障等）
四是廉洁自律（遵规守纪）
五是问题不足与改进方向
```

## 四、关键要素

### 4.1 导言必备

| 要素 | 说明 | 示例 |
|------|------|------|
| 年度定位 | 五年规划节点 | "2025年是'十四五'收官之年" |
| 重大背景 | 党的会议、中央决策 | "深入贯彻党的二十届四中全会精神" |
| 工作主线 | 本单位核心任务 | "全面落实招商引资'一号工程'" |

**时间节点表述**（必须准确）：
| 年份 | 正确表述 |
|------|----------|
| 2025年 | "十四五"收官之年 |
| 2026年 | "十五五"开局之年 |

### 4.2 核心业务板块

**开头必须用数据总括**：
> 2025年，全市内资完成172亿元，完成率101%；落地亿元项目43个，开工率79%。

**每条举措的结构**：
```
[机制创新] + [具体做法] + [实际成效]
```

**避免**：只有做法没有成效，或者只有成效没有做法。

### 4.3 问题不足的写法

**原则**：敢于直面但不过度渲染，每条简明扼要。

**好的写法**：
> 一是外资招引仍有较大差距，距离目标还有一定缺口。
> 二是重大项目招引还需突破，头部企业引进数量偏少。

**避免的写法**：
> 我们的工作还存在一些不足，需要进一步加强和改进。（太空）

### 4.4 结语的决心表态

**公式**：
```
明年定位 + 工作态度 + 奋斗目标
```

**示例**：
> 2026年是"十五五"开局之年。市投促中心将进一步提高政治站位、强化实干担当，为高质量建设共富共美现代化新慈溪作出更大贡献。

## 五、常见问题

| 问题 | 症状 | 改进 |
|------|------|------|
| 政治站位空转 | 大段政治表态但没有具体行动 | 表态后紧跟"具体做法" |
| 成绩堆砌 | 流水账式罗列 | 提炼3-4个核心亮点，深度展开 |
| 问题避重就轻 | 说的都是无关痛痒的小问题 | 直面真正的短板，但表述要建设性 |
| 展望空洞 | "进一步加强""不断提升" | 给出具体目标或可量化指标 |

## 六、篇幅参考

| 场景 | 字数 |
