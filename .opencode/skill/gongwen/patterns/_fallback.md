# 通用公文撰写策略

> 当用户请求的公文类型没有专门的 `patterns/*.md` 文件时，使用本策略。

## 一、适用场景

本文件适用于以下未覆盖类型：
- 综合汇报（zonghe.md 待补充）
- 党建工作（dangjian.md 待补充）
- 纪检工作（jijian.md 待补充）
- 其他未列明的公文类型

## 二、降级策略

### 第一步：类型识别

根据用户请求，判断公文的**核心叙事模式**：

| 模式 | 关键词 | 结构 |
|------|--------|------|
| **成果汇报** | 总结、述职、年度报告 | 做了什么 → 效果如何 → 下步打算 |
| **问题解决** | 整改、建议、情况说明 | 问题是什么 → 原因分析 → 解决方案 |
| **人物事迹** | 先进典型、表彰材料 | 身份定位 → 突出事迹 → 精神升华 |
| **工作部署** | 方案、通知、计划 | 为什么做 → 做什么 → 怎么做 → 谁来做 |

### 第二步：借鉴最相近的 Pattern

| 用户请求 | 最相近 Pattern | 借鉴要点 |
|----------|----------------|----------|
| 综合汇报、工作汇报 | `shuzhi.md` | 数据开头、分项举措、问题不足 |
| 党建工作材料 | `shuzhi.md` 政治建设部分 | 理论学习、主体责任、制度建设 |
| 纪检工作材料 | `xunshi.md` | 问题导向、原因剖析、整改措施 |
| 表彰推荐材料 | `xianjin.md` | 动词短语开头、成效导向、权威背书 |
| 情况说明 | `xunshi.md` 原因剖析部分 | 客观陈述、条目清晰、责任明确 |

### 第三步：构建框架

无论何种类型，遵循**金字塔原则**：

```
1. 开头：一句话说清核心结论/定位
2. 主体：3-4 个分项，每项"观点句 + 支撑内容"
3. 结尾：问题不足（如适用）+ 下步打算/决心表态
```

## 三、通用结构模板

### 汇报类公文

```markdown
【导言】
XXXX年是"十X五"[节点]之年。[单位]在[上级]的[领导/指导]下，
[总体定性]，现将有关情况报告如下：

【第一部分：政治站位】（如需要）
- 理论学习
- 重大精神贯彻

【第二部分：核心业务】
- 开头用数据总括
- 分项举措（机制 + 做法 + 成效）

【第三部分：党建/纪检】（如需要）
- 主体责任
- 制度建设

【结尾】
- 成绩肯定（1-2句）
- 问题不足（2-3条，简明扼要）
- 下步打算
```

### 情况说明类公文

```markdown
【开头】
关于[事项]的情况说明

【背景】
[事项的来龙去脉，客观陈述]

【具体情况】
1. [情况一]
2. [情况二]
3. [情况三]

【原因分析】（如需要）
- 客观原因
- 主观原因

【处理意见/下步措施】
1. [措施一]
2. [措施二]
```

## 四、注意事项

1. **先询问再动笔**：不确定的类型，先与用户确认结构框架
2. **灵活调整**：模板是起点，根据实际需求增删
3. **核心原则不变**：无论类型，始终遵循 `philosophy/core-principles.md`
4. **标注不确定项**：对于不确定的部分，标注 `【待确认：XXX】`

## 五、升级提示

如果某类公文频繁使用，建议：
1. 将本次撰写经验记录到 `memory/feedback.md`
2. 考虑为该类型创建专门的 `patterns/*.md`
