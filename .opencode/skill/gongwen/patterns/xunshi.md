# 巡视巡察整改方案撰写指南

> 巡视整改方案的本质：**向组织立军令状**。表明态度、明确责任、拿出行动。

## 一、核心逻辑

```
反馈问题 → 原因剖析 → 整改目标 → 整改措施 → 责任落实
    ↓          ↓          ↓          ↓          ↓
  照单全收    深挖根源    定准方向    务实管用    确保落地
```

**政治定位**：巡视整改是重大政治任务，态度必须端正，措施必须实在，不能走过场。

## 二、标准框架（六部分）

### 第一部分：巡视反馈问题及建议

| 要素 | 说明 |
|------|------|
| 反馈问题 | **原文引用**巡视组反馈的具体问题 |
| 巡视建议 | 从《巡视建议》中摘取对应建议 |
| 原因剖析 | 条目式，3-5条，每条50字以上 |

**原因剖析的维度**：
- 工作机制层面
- 能力水平层面
- 责任落实层面
- 思想认识层面

### 第二部分：工作架构

```
协调机制组成
├── 召集人：[责任市领导]
├── 办公室设在：[责任部门]
└── 成员单位：[部门列表]

协调机制工作责任
├── 研究制定整改落实方案
├── 组织推动各项整改举措落实
├── 定期听取整改工作进展情况汇报
├── 协调解决整改工作中遇到的重大问题
├── 及时报送整改工作进展情况
├── 定期开展工作调度
├── 组织开展督促检查
└── 直至问题销号
```

### 第三部分：整改目标任务

| 要素 | 说明 |
|------|------|
| 总体目标 | 一段概括性表述 |
| 具体指标 | 可量化的工作目标，条目式 |
| 制度性成果 | 需要出台的文件、建立的机制 |

### 第四部分：整改安排

按时间节点分阶段表述：

| 时间节点 | 内容 |
|----------|------|
| 2026年2月底前 | 阶段性目标 |
| 2026年4月底前 | 阶段性目标 |
| 2026年6月底前 | 完成目标 |
| 下一轮巡视前 | 常态长效机制 |

### 第五部分：整改措施

**数量**：3-7条  
**字数**：每条50字以上  
**时限**：原则上2026年4月底前

**每条措施必须标注**：
```
措施一：[具体内容]
〔责任领导：XXX，责任部门：XXX，完成时限：XXXX年X月底前〕
```

### 第六部分：工作要求

通常3-4条：
1. 提高政治站位
2. 确保整改质量
3. 突出标本兼治
4. 强化责任落实（可选）

## 三、常用表述

### 政治站位类
- 把抓好巡视整改作为重大政治任务
- 切实增强整改的政治自觉、思想自觉和行动自觉

### 整改态度类
- 问题不查清不放过
- 整改不到位不放过
- 责任不落实不放过
- 群众不满意不放过

### 工作机制类
- 建立整改工作台账，实行销号管理
- 以巡促改、以巡促建、以巡促治

## 四、撰写前确认清单

在动笔前，必须与用户确认：

### 工作架构类
- [ ] 召集人是哪位市领导？
- [ ] 成员单位有哪些部门？

### 整改目标类
- [ ] 总体目标是否需要提炼？
- [ ] 制度性成果具体是什么？

### 整改措施类
- [ ] 每条措施的责任领导是谁？
- [ ] 每条措施的责任部门是谁？
- [ ] 每条措施的完成时限是什么？

### 原因剖析类
- [ ] 是否有现成的原因剖析？
- [ ] 是否需要从相关材料中提炼？

## 五、注意事项

1. **反馈问题原文引用**：不得改写、弱化巡视组的反馈表述
2. **措施必须务实**：每条措施要有具体动作，不能只有态度
3. **责任必须明确**：责任领导、责任部门、完成时限缺一不可
4. **时限必须合理**：与整改安排中的节点对应
5. **口径必须一致**：同一问题在不同材料中的表述必须一致
