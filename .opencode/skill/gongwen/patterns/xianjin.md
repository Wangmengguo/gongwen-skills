# 先进事迹撰写指南

> 先进事迹的本质：**树典型、立标杆**。让读者看到一个具体的人/集体如何践行某种精神或完成某项使命。

## 一、核心逻辑

先进事迹不是简历，不是工作日志，而是**讲故事**。

```
身份定位 → 核心贡献 → 精神升华
   ↓           ↓          ↓
 他是谁     他做了什么   这说明什么
```

**关键转变**：
- 从"做了什么" → 到"做成了什么"
- 从"事务性工作" → 到"实质性贡献"
- 从"工作量" → 到"价值创造"

## 二、结构框架

```
┌─────────────────────────────────────────────────────────┐
│  开头定位句（1句）                                        │
│  身份 + 政治站位 + 总体定性                               │
├─────────────────────────────────────────────────────────┤
│  分项论述（2-4个维度，动词短语开头）                       │
│  ├─ [动词短语1]：体制机制建设 + 具名成果                  │
│  ├─ [动词短语2]：核心业务推进 + 实质成效                  │
│  └─ [动词短语3]：亮点工作 + 权威背书                      │
├─────────────────────────────────────────────────────────┤
│  结尾总结句（可选，视字数需要）                           │
│  品质定性 + 贡献升华                                      │
└─────────────────────────────────────────────────────────┘
```

## 三、字数分配

| 类型 | 字数要求 | 结构分配 |
|------|----------|----------|
| 先进个人（300字） | 约290字 | 开头50字 + 分项80字×3 |
| 先进集体（400字） | 约390字 | 开头60字 + 分项110字×3 |

## 四、素材优先级

| 素材类型 | 作用 | 优先级 | 示例 |
|----------|------|--------|------|
| 体制机制成果 | 体现顶层设计 | **高** | 主笔起草《XX实施方案》 |
| 项目落地成效 | 体现实质贡献 | **高** | 推动X个重大项目落地 |
| 权威背书 | 提升层次 | **高** | 获《浙江日报》报道（省级优先） |
| 量化数据 | 增强说服力 | 中 | 慎用，避免给人"只是完成工作量"的印象 |

## 五、定位升级

**核心原则**：突出"统筹推进"而非"服务保障"，强调"成效贡献"而非"工作量"。

| 事务性表述（避免） | 战略性表述（推荐） |
|--------------------|---------------------|
| 主笔起草各类文稿100余篇 | 扎实推进全市XX体制机制建设 |
| 会议组织、材料报送 | 项目统筹协调 |
| 对外联络 | 加大与市级部门、主体单位联络对接 |
| 确保任务落实 | 梳理解决难点堵点问题 |
| 后勤保障 | 有效推动重大项目落地 |
| 获报道 | 多次获《浙江日报》《XX日报》报道 |

## 六、常用动词短语

| 类型 | 示例 |
|------|------|
| 体制机制类 | 强化顶层设计、健全制度体系、完善工作机制 |
| 统筹协调类 | 落实综合保障、强化统筹协调、推进项目落地 |
| 宣传影响类 | 加大宣传力度、提升品牌影响、扩大对外影响 |
| 创新突破类 | 深化改革创新、推动机制创新、探索路径突破 |

## 七、模板示例

### 先进个人（300字以内）

> 该同志作为[单位][职务]，认真贯彻落实[上级要求]，立足本职岗位，扎实做好[核心职责]。**强化顶层设计**，扎实推进[体制机制建设]，主笔牵头起草[具名文件1]、[具名文件2]等重要体制机制文件。**落实综合保障**，认真做好[统筹协调工作]，加大与[相关单位]联络对接，[解决问题]，有效[实质成效]。**加大宣传力度**，[亮点工作]，推动[工作领域]多次获[省级媒体]、[市级媒体]宣传报道，[价值升华]。

### 先进集体（400字以内）

> 该集体认真贯彻落实[上级要求]，[总体定性]，在[核心工作]方面取得显著成效。**强化顶层设计**，[统筹推进+体制机制]，[具名文件]。**推进项目落地**，[协调落实+项目推进]，[实质成效]。**扩大对外影响**，[亮点工作]，[权威背书]，[价值升华]。该集体[品质描述]，为[上级单位/全市][工作领域]作出积极贡献。

## 八、注意事项

1. **人称统一**：全文使用第三人称（该同志/该集体）
2. **动词开头**：分项用动词短语引导，避免"在...上"
3. **成效导向**：突出"推动项目落地""解决难点问题"
4. **弱化事务**：避免强调"写材料、开会、后勤"等日常事务
5. **层级排序**：媒体背书省级在前、市级在后
6. **首尾灵活**：结尾总结句可省略，字数紧张时优先保留分项
