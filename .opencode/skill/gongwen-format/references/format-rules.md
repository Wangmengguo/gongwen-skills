# 公文格式规范速查

> 本文档用于公文格式检查和验证，包含所有禁止出现的格式和正确的格式规范。

---

## 禁止出现的内容

| 类型 | 禁止 | 正确 | 说明 |
|------|------|------|------|
| Markdown 标题 | `# 标题` | `标题` | 公文中不使用 Markdown 标记 |
| Markdown 加粗 | `**文字**` | `文字` | 公文中不使用格式标记 |
| 半角引号 | `"文字"` | `"文字"` | 必须使用中文全角引号 |
| 小标题独立成行 | 见下方示例 | 融入段落 | 小标题必须与内容同段 |
| 半角标点 | `,` `.` `;` `:` | `，` `。` `；` `：` | 必须使用中文全角标点 |
| Markdown 列表 | `- 项目` | `项目` | 使用序号代替列表符号 |
| Markdown 引用 | `> 引用` | `引用` | 直接使用文字 |
| Markdown 表格 | `\| 列 \|` | 纯文本表格或移除 | 公文中不使用 Markdown 表格 |
| Pandoc 遗留标记 | `[text]{.class}` | `text` | 清理所有技术标记 |

## 小标题处理规范

### 错误格式

```
（一）突出政治引领，思想共识持续巩固。

坚持把理论学习摆在首位，持续开展会员读书月活动。
```

**问题**：小标题独立成行，与内容分离。

---

### 正确格式

```
（一）突出政治引领,思想共识持续巩固。坚持把理论学习摆在首位，持续开展会员读书月活动。
```

**特点**：小标题与内容在同一段落，用句号分隔。

## 序号层级规范

| 层级 | 格式 | 示例 | 使用场景 |
|------|------|------|----------|
| 一级 | 中文数字+顿号 | 一、二、三、 | 主要章节 |
| 二级 | 括号中文数字 | （一）（二）（三） | 主要内容点 |
| 三级 | 阿拉伯数字+点 | 1. 2. 3. | 详细列举 |
| 四级 | 括号阿拉伯数字 | （1）（2）（3） | 细节说明 |

**注意**：
- 同一层级的序号格式必须统一
- 不能跨级使用（如直接从一级跳到三级）
- 每个层级的序号必须连续（不能跳号）

## 空行规范

### 一级标题空行

**正确格式**：

```
……上一段内容结束。

一、主要工作内容

（一）第一项工作……
```

**规则**：
- 一级标题前后各一个空行
- 与上下文清晰分隔

---

### 段落间空行

**错误格式**：

```
（一）第一项工作内容。

（二）第二项工作内容。
```

**正确格式**：

```
（一）第一项工作内容。
（二）第二项工作内容。
```

**规则**：
- 同级段落之间不使用空行
- 紧凑排列，节省空间

---

## 标点符号规范

### 全角标点

**必须使用全角**：
- 逗号：`，`（不是 `,`）
- 句号：`。`（不是 `.`）
- 分号：`；`（不是 `;`）
- 冒号：`：`（不是 `:`）
- 问号：`？`（不是 `?`）
- 感叹号：`！`（不是 `!`）
- 引号：`""`（不是 `""`）
- 括号：`（）`（不是 `()`）
- 顿号：`、`

---

### 引号配对

**检查规则**：
- 引号必须成对出现
- 左引号 `"` 和右引号 `"` 数量必须相等
- 引号不能嵌套使用（公文中避免复杂引用）

## 检查清单

### 格式检查

- [ ] 无 Markdown 标题符号（#、##、###）
- [ ] 无 Markdown 加粗符号（**、__）
- [ ] 无 Markdown 斜体符号（*、_）
- [ ] 无 Markdown 列表符号（-、*、+）
- [ ] 无 Markdown 引用符号（>）
- [ ] 无 Markdown 表格符号（|）
- [ ] 无 Pandoc 遗留标记（[text]{.class}）

---

### 标点检查

- [ ] 所有标点为中文全角
- [ ] 引号成对出现
- [ ] 引号为中文全角（""）
- [ ] 无半角逗号、句号、分号、冒号

---

### 结构检查

- [ ] 小标题已融入段落
- [ ] 一级标题前后有空行

- [ ] 序号层级正确且连续

---

### 内容检查

- [ ] 无技术性标记
- [ ] 可直接粘贴使用
- [ ] 格式清晰、易读

## 自动检测方法

### 检测 Markdown 符号

```bash
grep -E '^#{1,6} |^\*|^-|^\+|^>' <file>
```

### 检测半角引号

```bash
grep '"' <file>
```

### 检测半角标点

```bash
grep -E '[,\.;:!?]' <file>
```

### 检测 Pandoc 遗留标记

```bash
grep -E '\[.+\]\{\..*\}' <file>
```

## 参考示例

### 完整示例（正确格式）

```
2024年工作总结

一、主要工作成效

（一）突出政治引领，思想共识持续巩固。坚持把理论学习摆在首位，持续开展会员读书月活动，组织专题讲座12场，参与会员达300余人次。

（二）强化履职能力，参政议政成果丰硕。围绕"优化营商环境"等主题，形成调研报告5份，提交提案建议20件，其中3件被列为重点提案。

二、存在的问题

（一）基层组织建设有待加强。1. 部分支部活动开展不够经常。2. 会员参与度有待提高。

（二）调研深度有待提升。1. 部分调研报告针对性不强。2. 转化率有待提高。
```

## 常见错误及修正

| 错误 | 修正 | 说明 |
|------|------|------|
| `# 一、主要工作` | `一、主要工作` | 删除 Markdown 标题符号 |
| `**（一）工作内容**` | `（一）工作内容` | 删除加粗符号 |
| `"重要内容"` | `"重要内容"` | 半角引号改全角 |
| `活动,参与` | `活动，参与` | 半角逗号改全角 |
| `（一）标题<br>内容` | `（一）标题。内容` | 小标题融入段落 |
