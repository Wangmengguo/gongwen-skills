# Excel 转 Markdown 使用指南

## 快速开始

### 基本用法

```bash
# 方式 1：指定输出路径
python3 .opencode/skill/gongwen-format/scripts/excel2md.py input.xlsx output.md

# 方式 2：自动生成同名 .md 文件
python3 .opencode/skill/gongwen-format/scripts/excel2md.py input.xlsx
```

### 支持格式

- ✅ `.xlsx` - Office Open XML 格式（推荐）
- ❌ `.xls` - 旧版 Excel 格式（不支持，需先转换）
- ❌ `.et` - WPS 表格格式（不支持，需先转换为 .xlsx）

## 脚本特性

### 自动化处理

1. **智能表头检测**
   - 自动识别包含"序号"关键词的行作为表头
   - 跳过 Excel 中的标题行或合并单元格
   - 从真正的数据表头开始转换

2. **数据清理**
   - 移除单元格内的换行符（`\n`、`\r`）
   - 合并多余空格
   - 删除全空列

3. **格式优化**
   - 生成符合 GFM 规范的 Markdown 表格
   - 自动计算列宽，保持对齐
   - 正确处理中文字符宽度

## 常见问题

### Q1: 为什么 .et 文件不能转换？

**A**: `.et` 是 WPS 的专有格式，需要先用 WPS 或 Excel 打开并另存为 `.xlsx` 格式。

**操作步骤**：
1. 用 WPS 打开 `.et` 文件
2. 点击「文件」→「另存为」
3. 选择格式为「Excel 工作簿 (*.xlsx)」
4. 保存后再使用脚本转换

### Q2: 转换后表格列数不对？

**A**: 脚本会自动删除 Excel 中的全空列。如果需要保留空列，可以在空列中添加占位符（如 `-`）。

### Q3: 表头识别错误怎么办？

**A**: 脚本通过检测"序号"关键词来识别表头。如果你的表头不包含"序号"，建议：
1. 在 Excel 第一列添加"序号"列
2. 或手动编辑转换后的 Markdown 文件

### Q4: 如何处理多个 sheet？

**A**: 当前版本仅转换第一个 sheet。如需转换多个 sheet：
1. 在 Excel 中将每个 sheet 另存为单独的 `.xlsx` 文件
2. 分别转换每个文件

## 转换后验证

使用以下清单验证转换结果：

- [ ] 表头正确（第一行是列名，不是标题）
- [ ] 数据行数正确（对比 Excel 和 Markdown）
- [ ] 列数正确（无多余空列）
- [ ] 单元格内容无跨行
- [ ] 表格格式符合 GFM 规范
- [ ] 中文字符显示正常

## 技术细节

### 表头检测算法

```python
def detect_header_row(matrix):
    """检测真正的表头行"""
    for i, row in enumerate(matrix[:5]):  # 只检查前5行
        row_text = ' '.join(str(cell) for cell in row)
        if '序号' in row_text or '编号' in row_text:
            return i  # 返回表头行索引
    return 0
```

### 换行符处理

```python
# 清理换行符和多余空格
cell_value = str(cell_value).replace('\n', ' ').replace('\r', ' ')
cell_value = re.sub(r'\s+', ' ', cell_value).strip()
```

### 中文字符宽度计算

```python
# 中文字符占 2 个宽度单位，英文/数字占 1 个
display_width = sum(2 if ord(c) > 127 else 1 for c in str(cell))
```
