# 公文修改技能

> "好公文不是写出来的，是改出来的。修改的本质是重新编织——用更清晰的逻辑、更精准的语言，让信息更有效地传达。"

## 一、核心哲学

修改公文不是挑错别字，而是帮助文章更好地**完成使命**。

在动笔修改之前，先问三个问题：
1. **这篇文章要达到什么目的？** 目的决定修改方向
2. **读者是谁？** 读者决定表达方式
3. **哪里妨碍了目的的达成？** 这才是真正需要改的地方

**修改的优先级**：
```
逻辑问题 > 内容问题 > 表达问题 > 格式问题
```

格式错误很刺眼，但逻辑混乱才是致命伤。

## 二、渐进式修改流程

### 第一步：接收原文，明确意图

接收原文后，必须确认：

| 确认项 | 选项 | 影响 |
|--------|------|------|
| 修改意图 | 全面重写 / 局部优化 / 仅格式规范 | 决定修改深度 |
| 发文身份 | 市投促中心 / 某领导 / 全市视角 / 其他 | 决定口径和自称 |
| 铁打不动 | 哪些内容不能改？ | 划定修改边界 |
| 新增素材 | 是否有新数据/案例要补充？ | 影响内容调整 |
| 输出模式 | 直接改 / 出意见 / 两者都要 | 决定输出格式 |

**不确定就问，不要猜测。**

### 第二步：加载写作智慧（首次修改建议加载）

```
读取文件: ../gongwen/philosophy/core-principles.md
```

这份文件帮助你建立"好公文"的判断标准，而非机械套规则。

### 第三步：通读全文，输出诊断报告

从上到下通读，按优先级输出诊断：

#### 逻辑与结构问题（优先级最高）

- 核心观点是否清晰？读完能否一句话概括？
- 结构是否合理？各部分是否有逻辑关联？
- 是否有内容重复或遗漏？

#### 内容问题

- 是否有"正确的废话"？删掉后影响理解吗？
- 数据和案例是否支撑观点？
- 政治表态是否恰当？（不多不少）

#### 表达问题

- 是否有空洞套话堆砌？
- 是否有口语化表述？
- 口径是否一致？（自称、视角）

#### 格式问题

```
读取文件: ../gongwen/redlines/format-rules.md
```

- 标点是否规范？（全角/半角）
- 序号层级是否正确？
- 是否有残留的 Markdown 符号？

**诊断报告格式**：
```
【逻辑问题】
1. 第X段：[问题描述] → [建议]

【内容问题】
1. 第X段第X行：[问题描述] → [建议]

【表达问题】
1. 第X段：[原文] → [建议改为]

【格式问题】
1. 第X行：[问题] → [正确写法]
```

### 第四步：用户反馈

用户逐条确认：采纳 / 不采纳 / 调整方向

根据反馈调整修改计划。

### 第五步：分批次执行修改

**迭代轮次**：输出对照表
```
原：[原文]
改：[修改后]
理由：[为什么这样改]
```

**敲定轮次**：用户确认"可以了"后，输出最终纯净原文。

### 第六步：循环迭代

重复第四、五步，直到用户满意。

## 三、特殊文体检查

### 问题-举措型文章

适用于：调研报告、政协提案、整改方案

**核心原则**：问题部分只描述现状，不预写措施。

| 内容类型 | 归属 | 典型表述 |
|----------|------|----------|
| 现状描述 | 问题部分 | "目前...""现有..." |
| 差距分析 | 问题部分 | "与...相比存在差距" |
| 具体措施 | 举措部分 | "加快推进...""建议..." |

**检查项**：
- [ ] 问题部分是否混入"加快""推进""建议"等措施性表述？
- [ ] 举措是否与问题形成对应？

### 述职类文章

```
读取文件: ../gongwen/patterns/shuzhi.md
```

**检查项**：
- [ ] 是否开头即结论？（数据总括）
- [ ] 问题不足是否具体可改？
- [ ] 时间节点表述是否准确？（十四五/十五五）

### 先进事迹类文章

```
读取文件: ../gongwen/patterns/xianjin.md
```

**检查项**：
- [ ] 是否突出"成效"而非"工作量"？
- [ ] 动词短语是否有力？（避免"在...上"）
- [ ] 媒体背书是否按级别排序？

## 四、身份口径速查

| 发文身份 | 自称 | 对上级称谓 | 典型场景 |
|----------|------|------------|----------|
| 市投促中心 | 我中心、中心 | 市委市政府 | 工作汇报、述职 |
| 全市视角 | 我市、全市 | 省委省政府 | 综合汇报 |
| 某领导个人 | 我、本人 | 组织、上级 | 述职报告 |
| 政协界别 | 本界别 | 市委市政府 | 提案、调研 |
| 社会团体 | 本会、我会 | 市委统战部 | 工作汇报 |

**修改时务必检查全文口径一致性。**

## 五、核心约束（始终生效）

1. **不猜测意图**：把握不准就问
2. **诊断细颗粒度**：逐条列出，不笼统概括
3. **用户反馈优先**：AI诊断仅供参考
4. **分层次修改**：不一蹴而就
5. **全角标点**：""，。；：？！

## 六、修改完成后

1. 输出最终纯净原文
2. 附上"本次修改摘要"：
   - 改了哪几类问题
   - 共多少处
3. 如有未采纳的建议，简要列出供后续参考
