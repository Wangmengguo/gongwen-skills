# 公文撰写技能

本Skill用于撰写各类公文材料，包括汇报、巡视整改、党建、述职报告、纪检、综合材料等。

## 使用流程

### 第一步：读取核心规范（必须）

无论撰写何种类型的公文，必须先读取核心规范文件：
- **`references/core.md`** - 公文撰写核心规范（格式红线、语言约束、工作流程）

### 第二步：确认公文类型

向用户确认需要撰写的公文类型：
- 巡视巡察整改类
- 综合汇报类
- 党建工作类
- 述职报告类
- 纪检工作类
- 先进事迹类（先进个人/先进集体）

### 第三步：读取对应的详细规范

根据公文类型，读取对应的详细规范文件：

| 公文类型 | 参考文件 |
|----------|----------|
| 巡视巡察整改 | **`references/xunshi-xuncha.md`** |
| 综合汇报 | **`references/zonghe.md`**（待补充） |

### 第四步：读取核心纲领文件

当前重点工作的核心纲领文件：
- **招商引资"一号工程"实施方案**：`述职报告/慈溪市关于激发体制机制创新活力落实招商引资一号工程的实施方案.md`

撰写时需读取此文件，核心表述必须只字不差引用。

### 第五步：确认素材和框架

1. 向用户确认是否有参考模板
2. 向用户确认素材来源
3. 列出缺失信息并询问
4. 开始撰写

## 核心红线（速查）

- 全角标点：“”，。；：？！
- 禁止Markdown格式符号
- 小标题融入段落开头
- 不主观判断、不点名批评
- 不编造内容，缺失处留空询问
- 不允许未经确认的数值

## 引号规范（新增，必须遵守）

1. 公文正文中出现的引号，必须使用中文全角引号：前引号为“，后引号为”。
2. 严禁使用半角双引号："。
3. 所有引号必须成对出现，前后位置必须匹配，不得出现单个悬空引号。
4. 引号嵌套时，外层使用“”，内层使用‘’。
5. 涉及引用文件原文时，必须保持原文引号形式不变；如原文为“”，则只字不差引用。

## 撰写完成后

每次完成公文撰写后，必须执行以下操作：

1. **更新项目进度文档**：读取并更新`公文Skill项目进度.md`
   - 如果是新类型公文，更新"完成情况"表格
   - 添加新的范例文件路径
   - 在"迭代记录"中添加本次更新内容

2. **沉淀经验**：如果本次撰写涉及新的框架结构或规范，将其补充到对应的references文件中
