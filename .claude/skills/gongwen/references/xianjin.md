# 先进事迹类撰写规范

本文档适用于先进个人事迹、先进集体事迹等表彰类短文撰写。

## 一、行文结构

采用"总-分"两段式结构（结尾总结句可省略）：

```
┌─────────────────────────────────────────────────────────┐
│  开头定位句（1句）                                        │
│  身份 + 政治站位 + 总体定性                               │
├─────────────────────────────────────────────────────────┤
│  分项论述（2-4个维度，并列结构）                          │
│  ├─ [动词短语1]：统筹推进 + 体制机制建设 + 具名文件      │
│  ├─ [动词短语2]：协调落实 + 项目推进 + 实质成效          │
│  └─ [动词短语3]：亮点工作 + 权威背书 + 价值升华          │
├─────────────────────────────────────────────────────────┤
│  结尾总结句（可选，视字数需要）                           │
│  品质定性 + 贡献升华                                      │
└─────────────────────────────────────────────────────────┘
```

**核心原则**：突出"统筹推进"而非"服务保障"，强调"成效贡献"而非"工作量"。

## 二、撰写流程

### 第1步：明确三要素

| 要素 | 问题 | 示例 |
|------|------|------|
| **身份** | 谁？什么岗位？ | 办公室主任 |
| **核心贡献** | 推动了什么实质性工作？ | 体制机制建设、项目落地 |
| **亮点成效** | 今年2-4个最突出的成效？ | 体制创新、项目推进、宣传影响 |

### 第2步：搭建骨架

```
该同志/该集体作为[单位+职务]，[政治站位表态]，[总体定性]。
[动词短语1]，[统筹推进+体制机制+具名文件]。
[动词短语2]，[协调落实+项目推进+实质成效]。
[动词短语3]，[亮点工作+权威背书+价值升华]。
```

**注意**：结尾总结句视字数需要可省略，分项用动词短语开头更有力度。

### 第3步：填充素材

| 类型 | 作用 | 优先级 | 示例 |
|------|------|--------|------|
| **体制机制成果** | 体现顶层设计 | 高 | 《...实施方案》等体制机制文件 |
| **项目落地成效** | 体现实质贡献 | 高 | "推动重大项目落地" |
| **权威背书** | 提升层次 | 高 | 《浙江日报》报道（省级优先） |
| **量化数据** | 增强说服力 | 中 | 慎用，避免强调工作量 |

**素材导向调整**：
- 弱化"会议组织、材料报送、后勤保障"等事务性描述
- 强化"体制机制建设、项目统筹协调、难点问题解决"等实质性贡献
- 媒体背书按级别排序：省级在前，市级在后

### 第4步：控制字数

根据表格要求控制字数：

| 类型 | 字数要求 | 结构分配 |
|------|----------|----------|
| 先进个人（300字） | 约290字 | 开头50字 + 分项80字×3 |
| 先进集体（400字） | 约390字 | 开头60字 + 分项110字×3 |

## 三、速查模板

### 先进个人模板（300字以内）

```
该同志作为[单位][职务]，认真贯彻落实[上级要求]，立足本职岗位，扎实做好[核心职责]。[动词短语1]，扎实推进[体制机制建设]，主笔牵头起草[具名文件1]、[具名文件2]等重要体制机制文件。[动词短语2]，认真做好[统筹协调工作]，加大与[相关单位]联络对接，[解决问题]，有效[实质成效]。[动词短语3]，[亮点工作]，推动[工作领域]多次获[省级媒体]、[市级媒体]宣传报道，[价值升华]。
```

### 先进集体模板（400字以内）

```
该集体认真贯彻落实[上级要求]，[总体定性]，在[核心工作]方面取得显著成效。[动词短语1]，[统筹推进+体制机制]，[具名文件]。[动词短语2]，[协调落实+项目推进]，[实质成效]。[动词短语3]，[亮点工作]，[权威背书]，[价值升华]。该集体[品质描述]，为[上级单位/全市][工作领域]作出积极贡献。
```

### 常用动词短语（分项开头）

| 类型 | 示例 |
|------|------|
| **体制机制类** | 强化顶层设计、健全制度体系、完善工作机制 |
| **统筹协调类** | 落实综合保障、强化统筹协调、推进项目落地 |
| **宣传影响类** | 加大宣传力度、提升品牌影响、扩大对外影响 |
| **创新突破类** | 深化改革创新、推动机制创新、探索路径突破 |

## 四、撰写前确认清单

向用户确认以下信息：

- [ ] 先进个人还是先进集体？
- [ ] 字数要求？
- [ ] 单位全称和职务？
- [ ] 核心贡献是什么？（体制机制建设/项目推进/创新突破等）
- [ ] 今年2-4个最突出的成效？
- [ ] 有无体制机制成果（文件名、制度名）？
- [ ] 有无项目落地成效（项目名、实质成果）？
- [ ] 有无权威背书（省级媒体优先、上级表彰）？

## 五、语言特点

### 开头常用表述
- 认真贯彻落实中央和省、市关于...的决策部署
- 立足本职岗位，扎实做好...
- 紧紧围绕...中心工作

### 分项引导词（动词短语开头，更有力度）

| 避免使用 | 推荐使用 |
|----------|----------|
| 在文稿服务上 | 强化顶层设计 |
| 在综合保障上 | 落实综合保障 |
| 在服务一线上 | 加大宣传力度 |
| 在日常工作中 | 健全工作机制 |

### 结尾常用表述（可省略）
- 工作勤勉务实，有力保障了...
- 敬业奉献、担当作为，为...作出积极贡献
- 开拓创新、真抓实干，推动...取得明显成效

## 六、注意事项

1. **人称统一**：全文使用第三人称（该同志/该集体）
2. **动词开头**：分项用动词短语引导（强化/落实/加大），避免"在...上"
3. **成效导向**：突出"推动项目落地"、"解决难点问题"等实质成效
4. **弱化事务**：避免强调"写材料、开会、后勤"等日常事务性工作
5. **层级排序**：媒体背书省级在前、市级在后；成果按重要性排序
6. **首尾灵活**：结尾总结句可省略，字数紧张时优先保留分项内容
7. **避免堆砌**：量化数据慎用，避免给人"只是完成工作量"的印象

### 定位升级对照表

| 事务性表述（避免） | 战略性表述（推荐） |
|--------------------|--------------------|
| 主笔起草各类文稿100余篇 | 扎实推进全市XX体制机制建设 |
| 会议组织、材料报送 | 项目统筹协调 |
| 对外联络 | 加大与市级部门、主体单位联络对接 |
| 确保任务落实 | 梳理解决难点堵点问题 |
| 后勤保障 | 有效推动重大项目落地 |
| 获报道 | 多次获《浙江日报》《XX日报》报道 |
